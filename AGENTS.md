# TokenLint
Keep your design system consistent.
Audit, validate, and bind design tokens directly in Figma.

Keep runtime, pure audit rules, shared message contracts and React UI separate.
Use strict TypeScript and official Figma APIs. Keep plugin main free of DOM APIs
and keep the iframe free of Figma API calls. Ship local self-contained bundles.

v0.1.0 audits and manually binds. Never guess a collection role. Require explicit
semantic collection membership, compatible data type and established semantic
category. Treat ambiguous evidence as unverified. Never list primitives.
Use consumer-aware mode resolution and preserve variable identity independently.
Re-read live targets and candidates before mutation. Confirm value changes,
retain other paints, verify the result, and keep the audit snapshot consistent.

Future suggestions belong in an independent, replaceable module. Identify the
property first, filter by configured semantic collection, data type and semantic
compatibility, then resolve in the consumer mode. Rank exact matches first and
use context only among eligible candidates. Return at most three explainable
results, distinguish approximate or ambiguous matches and allow zero suggestions.
Keep manual selection available. No AI, remote services or bulk fixes in v0.1.0.
Do not begin later milestones until desktop QA passes. Keep data out of git.
